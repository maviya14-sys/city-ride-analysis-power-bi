# City Ride Analysis – Power BI Dashboard

## Overview

City Ride Analysis is a Power BI data analytics project designed to analyze taxi booking performance, revenue, vehicle types, cancellations, customer and driver ratings, and overall service quality.

The dashboard provides an interactive view of key business metrics and helps identify patterns across bookings, revenue, payment methods, vehicle categories, cancellation reasons, and ride distance.

## Dashboard Pages

### 1. Overall Report
Provides a high-level overview of booking performance, including:
- Total bookings
- Total cancellations
- Booking status by category
- Monthly booking trends

### 2. Vehicle Report
Analyzes performance across different vehicle types:
- Auto
- Bike
- eBike
- Go Mini
- Go Sedan
- Premier Sedan
- Uber XL

Metrics include booking value, successful booking value, average distance travelled, and total distance travelled.

### 3. Revenue Report
Analyzes:
- Booking value by payment method
- Revenue by vehicle type
- Ride distance trends
- Booking value by booking ID

### 4. Cancellation Report
Analyzes:
- Total bookings
- Successful bookings
- Cancelled bookings
- Cancellation rate
- Customer cancellation reasons
- Driver cancellation reasons

### 5. Rating Report
Compares customer and driver ratings across different vehicle types.

### 6. Summary Report
Provides additional business insights through:
- Revenue per kilometre
- Premium peak-hour performance
- Customer retention rate
- Booking value by day part
- Revenue by distance category
- Weekly booking trends
- Monthly revenue trends
- Overall service quality score

## Key Dashboard Metrics

The dashboard shows approximately:

- Total Bookings: 148.77K

- Cancelled Bookings: 37.42K
- Cancellation Rate: 25%
- Revenue per KM: 3.86M
- Premium Peak-Hour Performance: 72.53%
- Customer Retention Rate: 30.24%
- Service Quality Score: 77.05
